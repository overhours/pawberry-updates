# Pawberry Gacha

**Pawberry** is a free, cosy pink pixel-art cat-collecting gacha RPG.

Summon 325 cats from yarn balls, build a team of five, battle across 10 worlds and 10 bosses, climb the Endless Tower, go fishing, decorate your sanctuary, and rebirth for permanent bonuses. No ads and no real-money shop.

- **Download:** [latest release](https://github.com/overhours/pawberry-updates/releases/latest) (Windows installer, Windows portable, Linux AppImage and .deb) or on [itch.io](https://overhours.itch.io/pawberry)
- **Website:** [overhours.github.io/pawberry](https://overhours.github.io/pawberry/)

The installed game updates itself from this repository's releases.
