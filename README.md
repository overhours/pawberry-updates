# Pawberry updates

Release downloads for **Pawberry**, the cosy pink pixel-art cat-collecting game.

- **Installer:** `Pawberry-Setup-<version>.exe` (updates itself automatically)
- **Portable:** `Pawberry-Portable-<version>.exe` (no install needed)

Get the newest version from the [latest release](https://github.com/overhours/pawberry-updates/releases/latest).
